## 2. 业务与领域知识

### 2.1 方法论来源

项目基于 **Al Brooks 风格价格行为学**，提示词资产在 `prompt_engineering/`（约 20+ 个 `.txt` 文件），由程序只读加载。**改策略通常改 txt 而非改 Python**。

### 2.2 两阶段分析语义

| 阶段 | 名称 | 输出 | 作用 |
|------|------|------|------|
| **Stage 1** | 市场诊断 | `stage1_diagnosis` JSON | 周期位置、方向、闸门结果、逐 K 摘要、检测到的形态 |
| **Stage 2** | 交易决策 | `stage2_decision` JSON | 是否下单、订单类型、入场/止损/止盈、信号链 trace、`next_bar_prediction` |

**闸门短路**：Stage 1 的 `gate_result` 为 `wait` 或 `unknown` 时，程序 **跳过 Stage 2 API 调用**，直接生成「不下单」决策并落盘。

### 2.3 K 线序号约定（极易踩坑）

- **图表实时更新开启**：最右侧可有 **未收盘** 空心 K 线（forming bar），不参与 AI 分析。
- **提交分析时**：发给 AI 的始终是 **仅已收盘** K 线；K1 = 最新已收盘棒。
- **图表实时更新关闭** 或分析自动冻结时：画面切换为纯已收盘帧，未收盘棒消失。
- 详见 `docs/图表K线与分析快照说明.md`。

### 2.4 图表实时更新（可切换开关）

控制栏 **「图表实时更新」** 为 **可勾选按钮**（默认开启）：

| 开关状态 | 行为 |
|----------|------|
| **开启** | RefreshLoop 持续刷新；可显示未收盘空心棒；**分析进行中也可保持实时** |
| **关闭** | 冻结为纯已收盘帧；提交分析时自动进入此状态（若尚未关闭） |
| **分析结束** | `keep_analysis` 或 `auto_resume_chart_after_analysis` 可自动重新开启 |

实现入口：`pa_agent/gui/main_window.py` → `_on_chart_live_toggle`、`_chart_live_updates_enabled`。

### 4.1 启动与装配

| 文件 | 职责 |

| `pa_agent/main.py` | QApplication → 主题 → **许可校验** → `AppContext.bootstrap()` → `MainWindow` |

| 要点 | 说明 |
|------|------|
| 校验时机 | `main.py` 启动时 `ensure_license_or_exit` |

## 5. 关键数据流

```text
用户点击「提交分析」
    │
    ├─ build_analysis_frame（仅已收盘 N 根）
    ├─ PreflightDataGate（<20 根或指标全 NaN → 拒绝）
    ├─ 若图表实时更新关闭 → 冻结图表为分析帧
    │
    ▼
Stage 1 API → 校验/归一化 → route_strategy_files
    │
    ├─ gate_result ∈ {wait, unknown} → 短路 Stage 2
    └─ 否则 Stage 2 API → 校验/归一化
    │
    ▼
PendingWriter 落盘 + GUI 展示 + Notification（可选）
```

## 9. 改造注意事项

1. **提示词**：`prompt_engineering/*.txt` 为业务资产，改策略优先改 txt；合并分支时以上游提示词为准。
2. **K 线语义**：分析快照永远不含 forming bar；图表显示可与快照不同（实时模式下）。
3. **线程安全**：分析在 `QThread` worker 中运行；UI 更新须经 signal/slot。
4. **许可**：新增需门禁的功能应通过 `LicenseGuard` 注册，勿在业务代码里硬编码授权逻辑。
5. **数据源**：切换品种/周期会 cancel 进行中的 worker，并可能落盘 partial 记录。
