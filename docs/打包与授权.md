# PA Agent Windows 打包与激活授权

本文说明如何将 PA Agent 打成 Windows 安装包，以及如何用激活码控制使用期限。

## 一、能力概览

| 能力 | 说明 |
| --- | --- |
| 安装包 | PyInstaller 生成 `dist/PA_Agent/`，Inno Setup 生成 `dist/PA_Agent_Setup.exe` |
| 激活码 | Ed25519 离线签名，可设置到期时间、可选绑定机器码 |
| 防篡改 | 修改到期时间会验签失败 |
| 防回拨 | 记录上次校验时间，系统时间大幅回拨会锁定 |
| 运行时复检 | 每 5 分钟重新校验，过期立即退出 |

**重要说明**：任何纯客户端方案都无法做到 100% 防破解。本方案可挡住普通用户改时间、改本地文件、共享激活码等行为；若需更强保护，建议叠加代码签名、PyArmor/Nuitka 混淆、以及可选的在线心跳校验。

## 二、供应商：生成密钥与激活码

### 1. 首次生成密钥对（只做一次）

```powershell
cd E:\Dev\Trading\PA_Agent
python tools/license_keygen.py generate-keys
```

- 私钥：`tools/.license_keys/license_private.pem`（**切勿发给客户或打进安装包**）
- 公钥：`pa_agent/licensing/public_key.pem`（随程序打包）

重新生成密钥会使旧激活码全部失效。

### 2. 可视化签发工具（推荐）

构建供应商专用 exe：

```powershell
powershell -ExecutionPolicy Bypass -File tools/build_license_issuer.ps1
```

输出：`dist/PA_Agent_License_Issuer.exe`（单文件，可单独拷贝使用）

功能：
- **签发激活码**：选择私钥、设置天数/到期日、机器绑定、客户备注，一键生成并复制
- **验证激活码**：粘贴客户激活码检查是否有效
- **密钥管理**：首次使用可图形化生成密钥对

也可直接运行源码：

```powershell
python tools/license_issuer_gui.py
```

### 3. 命令行签发（可选）

绑定本机（客户把机器码发给你）：

```powershell
python tools/license_keygen.py issue --days 30 --machine ABCD1234EFGH5678 --holder "客户A"
```

不绑定机器（任意电脑可用，适合试用码）：

```powershell
python tools/license_keygen.py issue --days 7 --machine any --holder "试用"
```

指定到期日：

```powershell
python tools/license_keygen.py issue --expires 2026-12-31 --machine local
```

验证激活码：

```powershell
python tools/license_keygen.py verify "PAAG-..."
```

## 四、构建 Windows 程序

完整步骤、参数说明、Agent 检查表与排错见 **[构建EXE.md](构建EXE.md)**。

快速命令（在项目根目录）：

```powershell
# 可运行目录 dist/PA_Agent/PA_Agent.exe
powershell -ExecutionPolicy Bypass -File tools/build_windows.ps1

# 另生成安装包 dist/PA_Agent_Setup.exe（需 Inno Setup 6）
powershell -ExecutionPolicy Bypass -File tools/build_windows.ps1 -Installer
```

也可双击 `build.bat`。脚本会自动安装依赖、跑单元测试、执行 PyInstaller 与安全扫描。

安装后：

- 程序文件在 `C:\Program Files\PA Agent\`
- 用户配置、日志、授权状态在 `%APPDATA%\PA_Agent\`

## 五、客户激活流程

1. 首次启动弹出「激活」对话框
2. 复制机器码发给供应商
3. 输入收到的 `PAAG-...` 激活码
4. 激活成功后正常使用；到期或时间回拨会提示并退出

## 六、开发调试

**源码直接运行**（`python run.py` 或未 frozen 的入口）会**自动跳过**激活码检查，无需配置。

打包后的 `PA_Agent.exe`（PyInstaller 或 Nuitka 打包）仍须正常激活。

## 七、在线授权服务器（可选，更强防破解）

默认仅使用**离线** Ed25519 签名校验。若需在线吊销、集中管控，在打包前创建 `config/license_client.json`（勿提交 Git）：

```json
{
  "online_enabled": true,
  "server_url": "https://license.yourdomain.com",
  "client_api_key": "your-shared-client-key"
}
```

未创建该文件时，构建会自动使用 `license_client.example.json`（`online_enabled: false`）。

### 部署授权服务器

```powershell
pip install fastapi uvicorn
$env:PA_LICENSE_API_KEY = "your-shared-client-key"
python tools/license_server/server.py --host 0.0.0.0 --port 8765
```

- 健康检查：`GET /api/v1/health`
- 客户端激活：`POST /api/v1/activate`
- 运行时心跳：`POST /api/v1/heartbeat`
- 吊销授权：`POST /api/v1/revoke?license_id=...`（需 `X-Client-Key`）

开启在线模式后，激活与每 5 分钟复检都会请求服务器；无法连接或已被吊销则拒绝使用。

### 公钥打进安装包是否有问题？

**没有问题。** 公钥本来就是公开的，用于验证激活码签名；私钥仅保留在供应商的 `license_keygen` 与（可选）授权服务器上。攻击者替换公钥需要改安装包本身，配合代码签名可进一步提高成本。

## 八、隐私配置不会被打包

构建**只**包含 `config/settings.example.json`（无 API Key、无钉钉 Webhook、无 MT5 路径）。

以下目录/文件**不会**进入安装包：

- `config/settings.json`
- `records/`、`logs/`、`experience/`
- `tools/.license_keys/license_private.pem`

打包后 `tools/verify_build_safe.ps1` 会自动扫描 `dist/PA_Agent` 是否误含密钥特征。

用户首次运行安装版时，程序会把 `settings.example.json` 复制到 `%APPDATA%\PA_Agent\config\settings.json`，由用户自行填写配置。

## 九、离线防破解加固（已实现）

正式发布请优先使用 **Nuitka** 构建（`tools/build_windows_nuitka.ps1`），并了解以下机制：

| 威胁 | 加固措施 |
| --- | --- |
| 替换独立 `public_key.pem` 自签 | 公钥嵌入 `embedded_pubkey.py`，打包产物**禁止**出现 `public_key.pem`；构建前自动 `sync_embedded_pubkey.py` |
| 运行中回拨系统时间 | `last_seen_utc` 写入 DPAPI 加密文件 + Windows 注册表 `HKCU\Software\PA_Agent\last_seen_utc` |
| 删授权文件 + 回拨时间 + 重用旧码 | 注册表时间锚点；校验 `iat`（系统时间不得早于签发时间）；联网时 HTTP Date 交叉校验（偏差 >1h 拒绝） |
| 单点 patch 授权逻辑 | 启动、提交分析、两阶段编排、定时器（**90 秒**）多处 `require_active_license()` |
| PyInstaller 字节码易被逆向 | **Nuitka** 编译为 native，提高静态分析成本 |
| 源码调试绕过 | 仅 **打包版**（`is_packaged_build()`）强制授权；`python run.py` 仍跳过 |

**仍无法 100% 防止**：专业逆向 patch 校验函数、完全断网下的极端改时间。若需更强保护，见下文在线授权与代码签名。

### 构建命令（推荐）

```powershell
# 正式发布
powershell -ExecutionPolicy Bypass -File tools/build_windows_nuitka.ps1

# 密钥轮换后必须重新 sync + 打包
python tools/license_keygen.py generate-keys
powershell -ExecutionPolicy Bypass -File tools/build_windows_nuitka.ps1 -Clean
```

## 十、安全建议（进阶）

1. **私钥离线保管**：放在 U 盘或离线机器，仅用于 `license_keygen.py`
2. **代码签名**：对 `PA_Agent_Setup.exe` 做 Authenticode 签名，减少 SmartScreen 拦截
3. **一机一码**：正式客户使用 `--machine <指纹>`，不要发 `any`
4. **续期**：到期前重新签发新码，客户在原界面输入新码即可覆盖
5. **更强防护**：评估 Nuitka 编译、PyArmor 混淆、或增加在线授权服务器
