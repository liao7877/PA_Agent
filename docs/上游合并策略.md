# 上游合并策略（Trading Agent）

> 适用分支：**`trading-agent`**（你的生产主线）  
> 上游只读：**`upstream/main`**（`rosemarycox5334-debug/PA_Agent`）  
> 路径清单源码：`pa_agent/trading_agent/manifest.py`

---

## 1. 分支模型

```
upstream/main     ← git fetch upstream，不在此开发
      │
      │  定期 merge（见下文脚本）
      ▼
trading-agent     ← 所有定制只提交在这里
      │
      └── push → origin（你的 fork）
```

- **`main`**：可保留为纯上游快照，日常不用。
- **`main_backup`**：历史归档，不再维护。
- **新功能**：从 `trading-agent` 拉 `feat/*` 分支，合回 `trading-agent`。

首次建议在本仓库执行一次：

```powershell
.\scripts\setup-merge-drivers.ps1
git config --local rerere.enabled true
```

## 4. 架构：从根上减少冲突

定制代码集中在 **`pa_agent/trading_agent/`**：

| 模块 | 职责 |
|------|------|
| `entry.py` | 启动、许可、`Trading Agent` 应用名 |
| `bootstrap.py` | `enrich_app_context()` 挂载通知/持仓 |
| `chart_live.py` | 图表实时更新开关 |
| `record_handlers.py` | 分析完成通知、持仓 tick |
| `licensing_ui.py` | 授权菜单、提交门禁 |
| `settings_ui.py` | 设置页：通知、MT5 路径、跟踪时段 |
| `window_hooks.py` | MainWindow 一次性接线 |

上游更新 `main_window.py` 时，你通常只需确认这几行仍在：

```python
from pa_agent.trading_agent.chart_live import ChartLiveController
self._chart_live = ChartLiveController(self)
# … _setup_ui 末尾 …
from pa_agent.trading_agent.window_hooks import wire_main_window, wire_after_sidebar
wire_main_window(self, license_validator)
wire_after_sidebar(self)
```

`app_context.py` 末尾保留：

```python
from pa_agent.trading_agent.bootstrap import enrich_app_context
return enrich_app_context(ctx)
```
