## 分支模型

```
upstream/main  →  merge  →  trading-agent  →  push  →  origin
```

- 生产分支：**`trading-agent`**
- 上游只读：**`upstream/main`**
- 路径清单：`pa_agent/trading_agent/manifest.py`

## 快速命令

```powershell
.\scripts\setup-merge-drivers.ps1          # 每个 clone 一次
git config --local rerere.enabled true
.\scripts\merge-upstream.ps1               # 合并上游
```

## 文件分类

| 类 | 策略 | 代表路径 |
|----|------|----------|
| **A** | 保留我方 `merge=ours` | `trading_agent/`、`licensing/`、`notification/`、`positions/`、打包脚本 |
| **B** | 保留上游 `merge=theirs` | `prompt_engineering/**` |
| **C** | 人工合并 | `main_window.py`、`two_stage.py`、`deepseek_client.py`、`settings.py` 等 |
