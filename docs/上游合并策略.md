## 分支模型

```
upstream/main  →  merge  →  main  →  push  →  origin/main
```

| 分支 | 说明 |
|------|------|
| **`main`** | 生产主线（Trading Agent 定制版），日常开发 |
| **`upstream/main`** | 上游只读（`rosemarycox5334-debug/PA_Agent`） |
| **`archive/upstream-main`** | 引入定制前的纯上游快照归档 |

路径清单：`pa_agent/trading_agent/manifest.py`

## 快速命令

```powershell
git checkout main
.\scripts\setup-merge-drivers.ps1          # 每个 clone 一次
git config --local rerere.enabled true
.\scripts\merge-upstream.ps1               # 合并上游
```

## 文件分类

| 类 | 策略 | 代表路径 |
|----|------|----------|
| **A** | 保留我方 `merge=ours` | `trading_agent/`、`licensing/`、`notification/`、`positions/` |
| **B** | 保留上游 `merge=theirs` | `prompt_engineering/**` |
| **C** | 人工合并 | `main_window.py`、`two_stage.py`、`settings.py` 等 |

## 已知提示词定制差异（B 类例外）

默认 B 类跟上游，但 **`main` 上刻意保留以下本地改动**；合并 `upstream/main` 后若相关段落被覆盖，**须恢复我方版本**（不要整目录用 backup 覆盖）。

| 文件 | 段落 | 与上游差异 | 保留原因 |
|------|------|------------|----------|
| `prompt_engineering/二元决策.txt` | §10.3、紧凑通道专项 | 上游 `4d7dba5` 将盈亏比 **硬上限 1.5:1**；我方改为 **结构驱动、不设上限**，强趋势可取 2R+，弱行情可 1R～1.5R，底线 **>1:1**，以交易者方程为最终闸门 | Brooks 价格行为：止盈应由关键价位/支撑阻力等结构决定，而非先定 RR |
| `prompt_engineering/文件17-止损和止盈与仓位管理.txt` | 文件头「盈亏比原则」 | 补充与 §10.3 一致的说明，与 `文件17` 内 2R/3R、结构目标优先表述对齐 | 避免与 `二元决策` §10.3 及策略文件冲突 |

**合并后快速核对**（应无 `1.5:1` 上限、`首选目标不超过 1.5R` 等上游措辞）：

```powershell
rg "盈亏比上限 1\.5|首选目标不超过 1\.5R" prompt_engineering/
# 无输出 = 定制仍在
```

**Agent 规则**：合并冲突涉及上表文件时，**保留 `main` 侧（ours）对应段落**，其余 `prompt_engineering/**` 仍跟上游。
