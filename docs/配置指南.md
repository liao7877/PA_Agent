## 四、`settings.json` 字段详解

### 4.1 `provider` — AI 接口

| 字段 | 类型 | 说明 |
|------|------|------|
| `model` | string | 模型名，须与网关一致，如 `deepseek-chat`、`claude-sonnet-4-6` |
| `base_url` | string | OpenAI 兼容 API 根地址 |
| `api_key_encrypted` | string | DPAPI 加密后的 Key；空表示未配置 |
| `thinking` | bool | 是否启用思考/推理扩展参数（依模型与网关） |
| `reasoning_effort` | string | `low` / `medium` / `high` / `max` |
| `context_window` | int | 上下文窗口大小（tokens），用于占用提示 |

#### 常用 Base URL 示例

| 服务商 | `base_url` 示例 | 备注 |
|--------|-------------------|------|
| DeepSeek 官方 | `https://api.deepseek.com` | 部分客户端需加 `/v1`，以文档为准 |
| 第三方代理 | `https://www.packyapi.com/v1` | PackyAPI 等兼容网关 |
| 云雾等 | 按服务商文档填写 | 模型名必须与网关支持列表一致 |

**推荐**：在 GUI **设置** 中填写 Key，程序会用 Windows DPAPI 加密写入 `api_key_encrypted`，避免明文落盘。

### 4.2 `general` — 通用与界面

| 字段 | 默认值 | 说明 |
|------|--------|------|
| `analysis_bar_count` | 100 | 参与分析的 K 线数量（2–5000） |
| `refresh_interval_ms` | 1000 | 图表刷新间隔（毫秒） |
| `context_warning_threshold_pct` | 80 | 上下文占用告警阈值（%） |
| `last_data_source` | `mt5` | 上次数据源：`mt5` / `tradingview` |
| `last_tradingview_exchange` | `OANDA` | TV 默认交易所 |
| `last_symbol` | `XAUUSDm` | 默认品种（MT5 名须含后缀） |
| `last_timeframe` | `15m` | 默认周期 |
| `decision_stance` | `balanced` | 阶段二倾向，见下表 |
| `incremental_max_new_bars` | 10 | 自动增量最大新增 K 数；0=关闭 |
| `auto_resume_chart_after_analysis` | true | 分析结束后是否自动恢复图表刷新 |
| `decision_flow_auto_play` | true | 决策树自动播放 |
| `decision_flow_play_seconds` | 50 | 决策树播放间隔（秒） |
| `stream_pane_font_pt` | 11 | 实时面板字体 |
| `chart_seq_label_font_pt` | 7 | K 线序号标签字体 |

#### `decision_stance` 取值

| 值 | 含义 |
|----|------|
| `conservative` | 保守，更少交易信号 |
| `balanced` | 平衡（默认） |
| `aggressive` | 激进 |
| `extreme_aggressive` | 极端激进 |

### 4.3 `prompt` — 提示词与经验库

| 字段 | 说明 |
|------|------|
| `stage2_load_full_strategy_library` | 阶段二是否加载完整策略库 |
| `experience_max_entries` | 经验库注入条数上限 |
| `experience_max_chars_per_entry` | 每条经验最大字符 |
| `stage1_inject_pattern_briefs` | 阶段一是否注入形态简报 |

### 4.4 `validation` — JSON 校验

| 字段 | 说明 |
|------|------|
| `normalization_mode` | `strict` 等，控制 JSON 规范化严格度 |
| `trace_semantic_checks` | 决策 trace 语义检查 |
| `strict_bar_by_bar_features` | 逐 K 特征严格校验 |
| `disable_truncation_repair` | 禁用截断修复 |

## 五、GUI 设置项（与 JSON 对应）

启动程序 → **设置**：

1. **API**：Base URL、模型、API Key、思考模式、推理强度、上下文窗口  
2. **通用**：K 线数量、刷新间隔、交易倾向、增量阈值、字体等  
3. **TradingView**（可选）：用户名/密码（加密存储），缓解匿名限速  

保存后写入 `config/settings.json`。

## 六、数据源配置

### 6.1 MT5（推荐）

1. 安装 MetaTrader 5 并登录券商账户  
2. `general.last_data_source` 设为 `mt5` 或在界面选 **MT5**  
3. **品种名**必须与 MT5「市场报价」**完全一致**（如 `XAUUSDm`、`US500m`）  

#### 多套 MT5：指定终端路径

本机安装多个券商/版本 MT5 时，用 `general.mt5_terminal_path` 指定要连接的那一套：

| 配置方式 | 操作 |
|----------|------|
| **GUI** | **设置 → 通用设置 → MT5 终端路径** |
| **JSON** | 编辑 `config/settings.json` 中 `general.mt5_terminal_path` |

可填 **安装目录**（程序自动找 `terminal64.exe`），或 **exe 完整路径**：

```json
"mt5_terminal_path": "D:\\Hantec\\MetaTrader 5"
```

```json
"mt5_terminal_path": "C:\\Program Files\\MetaTrader 5 EXNESS\\terminal64.exe"
```

- **留空**：连接当前已运行实例，或系统默认安装（多开时可能连错）  
- **修改后**：重启 Trading Agent，或在界面 **数据来源** 切到 TradingView 再切回 MT5  

在资源管理器中：对 MT5 快捷方式 → **打开文件所在位置**，即可看到 `terminal64.exe` 所在目录。

验证：查看 `logs/pa_agent.log`，应出现 `MT5 initialize with terminal path: ...` 及 `terminal=券商名`。

验证连接：启动 Trading Agent 后，状态栏或日志应出现 MT5 已连接；若无 K 线，在 MT5 中先打开该品种图表。

### 6.2 TradingView

1. 界面数据来源选 **TradingView**  
2. 点击 **获取数据** 开始拉取  
3. `refresh_interval_ms` 建议：日线 3000–5000ms，分钟线 1000–2000ms（匿名模式易限流）  

#### tvdatafeed 已知问题修复（本机已处理）

若 TV 全部报 `Connection to remote host was lost`，编辑：

`C:\Python313\Lib\site-packages\tvDatafeed\main.py`

将：

```python
__ws_headers = json.dumps({"Origin": "https://data.tradingview.com"})
```

改为：

```python
__ws_headers = {"Origin": "https://data.tradingview.com"}
```

验证：

```powershell
python -c "from tvDatafeed import TvDatafeed, Interval; df = TvDatafeed().get_hist('XAUUSD', 'OANDA', Interval.in_daily, n_bars=2); print('OK:', len(df), 'bars')"
```

#### 股票名称别名

复制并编辑：

```powershell
copy config\tv_symbol_aliases.example.json config\tv_symbol_aliases.json
```

在 JSON 中添加「显示名 → TV 品种/交易所」映射。

## 七、安全与密钥

1. **勿**将 `config/settings.json` 提交到 Git（已在 `.gitignore`）  
2. Key 仅通过 GUI 保存或本地编辑后由程序加密  
3. 若 Key 曾泄露，立即在服务商处**轮换**  
4. 可选启用 Git 密钥扫描：

```powershell
powershell -ExecutionPolicy Bypass -File tools\setup_git_secrets.ps1
```

## 八、依赖重装与故障排查

### 完整重装依赖

```powershell
cd E:\Dev\Trading\PA_Agent
pip install -e . -i https://mirrors.aliyun.com/pypi/simple/ --trusted-host mirrors.aliyun.com
```

### 分项安装（某包失败时）

```powershell
pip install PyQt6 pyqtgraph openai tiktoken MetaTrader5 cryptography pywin32 -i https://mirrors.aliyun.com/pypi/simple/ --trusted-host mirrors.aliyun.com
pip install -e . --no-deps
```

### tvdatafeed 无法从 GitHub 克隆

- 仅使用 MT5 时可暂时跳过（TV 数据源不可用）  
- 或从 [GitHub 下载 ZIP](https://github.com/rongardF/tvdatafeed) 解压后：`pip install .`  
- 本机若存在临时克隆目录，可：`pip install C:\Users\Administrator\AppData\Local\Temp\pip-install-*\tvdatafeed_*`

### 配置损坏

```powershell
del E:\Dev\Trading\PA_Agent\config\settings.json
```

重启程序会重建默认配置，再在设置中重新填写 API。

### 日志位置

`E:\Dev\Trading\PA_Agent\logs\pa_agent.log`
