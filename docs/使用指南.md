# Trading Agent 使用指南

> 本机部署路径：`E:\Dev\Trading\PA_Agent`  
> 窗口标题：**Trading Agent**

---

## 一、项目是什么

**Trading Agent** 是一款运行在 Windows 上的 **价格行为（Price Action）AI K 线分析辅助工具**，面向主观交易者：

- 从 **MT5** / **TradingView** / **yfinance** / **AkShare** 读取 OHLCV K 线（**不是**截图识图）
- 本地计算 EMA20、ATR14、K 线几何特征
- 经大模型 **两阶段分析**：阶段一市场诊断 → 策略路由 → 阶段二交易决策
- 在图表上叠加入场/止损/止盈参考线，并完整落盘分析记录

**重要边界**：仅辅助分析，**不连接券商、不自动下单**。交易决策后果自负。

## 二、启动方式

任选其一：

| 方式 | 操作 |
|------|------|
| **推荐** | 双击项目根目录 `运行智能体.bat` |
| 命令行 | `cd E:\Dev\Trading\PA_Agent` 后执行 `python run.py` |
| 模块方式 | `python -m pa_agent.main` |
| 安装入口 | `pa-agent`（需 `pip install -e .`） |

### 首次启动检查清单

1. **MetaTrader 5** 已打开并已登录（使用 MT5 数据源时）
2. 打开 **设置**，填写 AI 的 **Base URL**、**模型**、**API Key**（见《配置指南》）
3. 控制栏选择 **数据来源**、**品种**、**周期**，点击 **获取数据**，确认图表有 K 线
4. 打包版需完成 **授权激活**（源码运行自动跳过）

## 三、主界面速览

```
┌──────────────────────────────────────────────────────────────────┐
│ [数据来源] [交易所] [品种] [周期]  ☑等待收盘  [提交分析][增量分析] … │
├─────────────────────────────┬────────────────────────────────────┤
│  K 线图（蜡烛 + EMA20）      │  实时 │ 决策流 │ 可视化 │ 决策 …  │
│  入场/止损/止盈线            │        AI 侧边栏                    │
└─────────────────────────────┴────────────────────────────────────┘
```

### 控制栏常用操作

| 控件 | 说明 |
|------|------|
| **数据来源** | `MT5`（默认）、`TradingView`、`AkShare`、`yfinance` |
| **品种** | 须与数据源一致，如 MT5 的 `XAUUSDm`（含后缀 `m`） |
| **周期** | 1m / 5m / 15m / 1h / 4h / 1d |
| **等待收盘** | 勾选后，提交分析前等待当前未收盘 K 走完 |
| **提交分析** | 完整两阶段 AI 分析 |
| **增量分析** | 基于上一轮成功记录，只分析新增已收盘 K 线 |
| **演示模式** | 回放已保存记录，不调用真实 API |
| **图表实时更新** | **可勾选开关**（默认开启）：开启时图表持续刷新并显示未收盘空心 K 线；关闭时冻结为纯已收盘画面。**分析进行中也可保持开启** |
| **持续跟踪** | 新 K 线收盘后自动触发增量分析（可配跟踪时段） |

**K 线数** 在 **设置 → 通用** 中配置（默认 100 根，范围 2–1000）。

## 四、典型工作流

1. 选择数据源、品种、周期 → **获取数据**
2. 确认 **图表实时更新** 已开启，观察 K 线与 EMA
3. （可选）勾选 **等待收盘**
4. 点击 **提交分析** → 侧栏「实时」页查看流式输出
5. 完成后查看「决策」页、图表 overlay 线、「未来走势」预测
6. 可在「原始」页检查 JSON；记录自动保存到 `records/pending/`
7. （可选）开启钉钉/Bark 通知，分析完成推送到手机

### 图表实时更新说明

- **开启**（默认）：最右侧显示浅色 **空心未收盘 K 线**，便于盯盘；分析时图表可继续动
- **关闭**：画面冻结为 **仅已收盘** K 线，与发给 AI 的数据一致（未收盘棒消失）
- 若关闭开关后提交分析，状态栏会显示「图表已冻结」
- **设置 → 通用** 可勾选「分析完成后自动恢复图表实时更新」

详见 `docs/图表K线与分析快照说明.md`。

## 五、设置要点

| 分类 | 常用项 |
|------|--------|
| **Provider** | Base URL、模型、API Key、上下文窗口 |
| **通用** | K 线数、刷新间隔、决策倾向、自动恢复图表、持续跟踪 |
| **通知** | 钉钉 Webhook、Bark Key |
| **跟踪时段** | 限制自动跟踪的星期与时间段 |

完整字段见 `docs/配置指南.md`。

## 七、常见问题

| 问题 | 处理 |
|------|------|
| 图表无数据 | 确认 MT5 已登录或 TV 网络可达；点击「获取数据」 |
| 分析按钮灰色 | 等待上一轮分析结束，或检查 Preflight（K 线不足 20 根） |
| 提交后少 1 根 K 线 | 正常：未收盘棒不进入分析；开启「图表实时更新」可继续看到它 |
| API 报错 | 检查设置页 API 健康检测；查看 `logs/pa_agent.log` |
| 打包版无法启动 | 完成授权激活，见 `docs/打包与授权.md` |
