# Trading Agent 文件索引（按模块）

> 快速查找「这个文件是干什么的」。完整说明见 `docs/项目交接文档.md`。

---

## 入口与装配

| 文件 | 说明 |
|------|------|
| `run.py` | 开发启动脚本（调用 `pa_agent.main`） |
| `pa_agent/main.py` | 程序入口：QApp → 许可 → bootstrap → MainWindow |
| `pa_agent/app_context.py` | `AppContext.bootstrap()` 依赖注入 |
| `pa_agent/config/paths.py` | 项目路径常量（config/records/experience/prompt） |
| `pa_agent/config/settings.py` | Settings Pydantic 模型、load/save |
| `pa_agent/config/tracking_schedule.py` | 跟踪时段判断逻辑 |

## ai/ — LLM 与分析逻辑

| 文件 | 说明 |
|------|------|
| `deepseek_client.py` | OpenAI 兼容 API 客户端，`stream_chat()`，GPT-5/Agnes 适配 |
| `prompt_assembler.py` | 组装 Stage1/2 messages，注入 K 线/特征/经验/策略 |
| `router.py` | `route_strategy_files()` 策略 txt 路由 |
| `pattern_routing.py` | detected_patterns 补全与 brief |
| `json_validator.py` | JSON 校验主入口，截断修复 |
| `stage1_normalizer.py` | Stage1 字段归一化 |
| `stage2_normalizer.py` | Stage2 字段归一化 |
| `trace_normalize.py` | gate_trace / decision_trace 格式统一 |
| `coherence_checks.py` | 字段交叉一致性校验 |
| `trace_semantic_checks.py` | trace 语义校验（可选） |
| `decision_nodes.py` | PreflightDataGate + DecisionNodeEngine |
| `decision_tree.py` | 闸门短路响应构建 |
| `decision_stance.py` | 交易倾向枚举与 prompt 指引 |
| `kline_features.py` | K 线几何特征计算 |
| `api_health.py` | API 异常 payload 结构 |
| `session_ledger.py` | 会话 Token 累计与告警 |
| `token_counter.py` | tiktoken 计数 |
| `validation_messages.py` | 校验错误用户可读文案，`format_preflight_failure` |
| `qclaw_connector.py` | QClaw Agent Provider 同步 |
| `workbuddy_connector.py` | WorkBuddy Provider 同步 |
| `cycle_enums.py` | 周期位置等枚举 |
| `prompts/schemas.py` | Stage1/2 JSON Schema |
